# Telegram Task Bot

Простой бот на Python с использованием `aiogram` для командной работы.

## Описание

Бот сохраняет задачи в SQLite и позволяет просматривать их списком или экспортировать в CSV.

## Команды

- `/start` — приветствие и инструкции
- `/add <текст>` — добавить задачу в общий список
- `/list` — показать все задачи
- `/list_csv` — отправить файл `tasks.csv` с задачами

## Структура проекта

- `main.py` — точка входа
- `bot/handlers.py` — обработчики команд и логика ответов
- `bot/keyboards.py` — простая клавиатура
- `db/database.py` — инициализация SQLite
- `db/tasks.py` — работа с таблицей `tasks`
- `utils/csv_export.py` — экспорт задач в CSV

## Запуск

1. Обновите инструменты сборки Python:

```bash
python -m pip install --upgrade pip setuptools wheel
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

> `aiogram==3.30.0` использует `aiohttp<3.15,>=3.9.0`, что обеспечивает совместимость с Windows и Python 3.12.

3. Создайте файл `.env` на основе примера:

```bash
copy .env.example .env
```

4. Откройте `.env` и вставьте свой токен:

```text
TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН_ЗДЕСЬ
```

5. Запустите бота:

```bash
python main.py
```

> В `requirements.txt` не указана версия `aiohttp`, чтобы `aiogram` сам выбрал совместимую версию.

Если хотите, можно также задать токен через системную переменную окружения `TELEGRAM_BOT_TOKEN`.

## Примечания

- При первом запуске создается база `tasks.db`.
- Если команда `/add` не содержит текста, бот попросит ввести задачу.
- При ошибках бот отправит сообщение о проблеме и сохранит запись в лог.
