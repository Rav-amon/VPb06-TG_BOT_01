# Telegram-бот с долгосрочной памятью

Бот на `aiogram` общается через нейросеть с OpenAI-совместимым API.
После каждого ответа тезисы диалога пишутся в SQLite. При следующем сообщении
и после перезапуска они снова попадают в системный промпт.

В чат уходит только текст ответа. Новые тезисы печатаются в консоль.
Уже сохранённый список можно запросить командой `/theses`.

## Команды

- `/start` — короткая подсказка
- `/theses` — показать тезисы этого пользователя из базы
- `/reset` — принудительно стереть память и начать диалог заново
- любое текстовое сообщение — диалог с учётом сохранённых тезисов

`/reset` удаляет таблицу пользователя. Следующий ответ собирается без старого контекста.
Таблица создаётся снова при первом новом сообщении.

## Как устроена память

- База: `memory.db`
- У каждого пользователя своя таблица `user_<telegram_id>`
- Таблица создаётся при первом сообщении
- В каждой строке один тезис и время записи в UTC
- Перед новым ответом все тезисы читаются через SQL и добавляются в системный промпт
  с пометкой, что это тезисы из базы данных

Нейросеть возвращает JSON с двумя ключами:

```json
{
  "theses": ["тезис по вопросу", "тезис по ответу"],
  "message": "текст, который уходит в чат"
}
```

## Структура

- `main.py` — запуск бота и загрузка уже сохранённого контекста
- `bot/handlers.py` — команды и диалог
- `bot/neural.py` — системный промпт, запрос к API и разбор JSON
- `db/database.py` — SQLite: чтение, запись и очистка тезисов
- `requirements.txt` — зависимости
- `.env.example` — образец переменных окружения

## Запуск

1. Обновите инструменты сборки Python:

```bash
python -m pip install --upgrade pip setuptools wheel
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` на основе примера:

```bash
copy .env.example .env
```

4. Заполните `.env`:

```text
TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН
OPENAI_API_KEY=ВАШ_КЛЮЧ
OPENAI_MODEL=gpt-6-luna
OPENAI_BASE_URL=https://api.openai.com/v1
```

На `api.openai.com` имя модели пишется без префикса провайдера: `gpt-6-luna`.
Префикс вида `openai/gpt-6-luna` нужен только другому адресу, например OpenRouter.
`OPENAI_BASE_URL` можно заменить на любой совместимый API.

5. Запустите бота:

```bash
python main.py
```

При старте бот открывает базу и пишет в лог, сколько тезисов уже сохранено.
Эти тезисы подставляются в системный промпт, когда пользователь снова пишет.
После правки `.env` процесс нужно перезапустить: он не перечитывает файл сам.
